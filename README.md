# duo-lab

iPhone Duo の Safari を実機で確かめるためのテスト用のページです。

- `index.html`：確かめる項目の一覧
- `measure.html`・`column.html`・`under.html`・`events.html`・`posture.html`・`newtab.html`：測る・見るためのページ
- `lp.html`：右の列での見切れを比べる、架空のゲームの LP（実在の作品・会社とは関係ありません）
- `r.html`：記録を QR で受け取るページ

記録は端末の中（localStorage）にだけ残り、どこにも送りません。
